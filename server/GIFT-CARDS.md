# 礼品卡

- 后台「礼品卡管理」选择金手指卡或月卡，一批可生成 1–10 张，默认 10 张。
- 月卡增加 30 天会员；金手指卡仅增加金手指免广告访问权益，默认 30 天，可配置天数。不改变普通月卡的金手指广告规则。
- 生成后立即复制保存卡密。服务端只保存哈希和尾号，无法找回完整卡密；刷新或生成下一批前请先保存。
- 用户在「我 → 礼品卡」输入卡密兑换，下方分别显示会员和金手指权益、北京时间到期时间。
- 未过期权益顺延，到期后重新从兑换时间开始计算；永久会员保持永久。每张卡只可兑换一次，同一账号重试不会重复增加天数。
- 后台记录可分页查看卡密尾号、类型、天数、兑换状态、兑换账号 ID 和时间。

测试：`node --test test/gift-cards.test.js`（在 server 目录执行）。
