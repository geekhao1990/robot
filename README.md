# 仿小红书微信小程序

一个使用**原生微信小程序**开发的仿小红书（RED）App，前端 + 本地 Mock 数据，
无需后端即可完整体验。涵盖首页瀑布流、笔记详情、搜索、发布笔记、个人中心与登录。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| 🏠 首页瀑布流 | 双列瀑布流（按图片比例自动均衡分列）、分类标签切换、下拉刷新、上拉加载更多 |
| 📝 笔记详情 | 图片轮播 + 预览、正文 / 话题标签、点赞 / 收藏 / 评论、关注作者 |
| 🔍 搜索 | 搜索历史、热门搜索、按标题 / 正文 / 标签 / 作者匹配结果（瀑布流展示） |
| ➕ 发布笔记 | 选图（最多 9 张）、标题 / 正文、话题标签、分类，发布后写入本地并跳转详情 |
| 👤 个人中心 | 个人资料、关注 / 粉丝 / 获赞、笔记 / 收藏 / 赞过三个 Tab |
| 🔐 登录 | 头像昵称登录 / 演示账号一键登录，登录态持久化 |
| 🙋 他人主页 | 查看作者资料与其全部笔记、关注按钮 |

所有点赞、收藏、关注、登录态、已发布笔记均通过 `Storage` 持久化，重启小程序后保留。

## 🚀 运行方式

1. 用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   打开本项目根目录（包含 `project.config.json`）。
2. AppID 可使用「测试号」。
3. **重要**：Mock 数据使用了在线占位图（`picsum.photos` / `pravatar.cc`），
   请在开发者工具中开启
   **「详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**，
   否则图片无法加载。正式上线时需替换为已备案并加入白名单的图片域名。

## 📁 目录结构

```
robot/
├── project.config.json        # 项目配置（miniprogramRoot 指向 miniprogram/）
└── miniprogram/
    ├── app.js / app.json / app.wxss   # 全局逻辑、页面注册、tabBar、全局样式
    ├── components/
    │   └── note-card/          # 瀑布流笔记卡片组件
    ├── pages/
    │   ├── index/              # 首页瀑布流
    │   ├── detail/             # 笔记详情
    │   ├── search/             # 搜索
    │   ├── publish/            # 发布笔记
    │   ├── profile/            # 个人中心（tabBar）
    │   ├── user/               # 他人主页
    │   └── login/              # 登录
    ├── utils/
    │   ├── api.js              # 模拟接口层（基于 mock 数据，返回 Promise）
    │   ├── store.js            # 本地状态 + 持久化（登录态 / 点赞 / 收藏 / 关注 / 我的笔记）
    │   └── util.js             # 工具函数（数字格式化、相对时间、toast）
    └── mock/
        └── data.js            # 模拟用户、笔记、分类、热搜数据
```

## 🔌 接入真实后端

当前数据来自 `utils/api.js` + `mock/data.js`。要接入真实后端，
只需保持 `api.js` 中各方法的函数签名与返回结构不变，将内部实现替换为
`wx.request` 调用即可，页面层无需改动。
