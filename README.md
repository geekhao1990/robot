# 仿

一个使用App，前端 + 本地 Mock 数据，
无需后端即可完整体验。涵盖首页瀑布流、笔记详情、搜索、发布笔记、个人中心与登录。
另含一个可选的 **Node 后端 + 网页管理后台**（`server/`，零依赖即可运行），
可把数据切换到真实接口并在后台维护（见 `server/README.md`）。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| 🏠 首页瀑布流 | 顶部「首页 / 发现 / 关注」导航 tab、双列瀑布流（按图片比例自动均衡分列）、下拉刷新、上拉加载更多 |
| 📝 笔记详情 | 图片轮播(圆点指示器) + 预览、正文 / 话题标签、点赞 / 收藏、关注作者；评论支持二级回复、评论点赞、删除自己评论(二次确认)；转发(微信好友列表 / 公众号) |
| 🎓 收费笔记 | 发布时可切换「收费笔记」类型；详情无评论/转发，改为「获取课程」：观看微信激励广告后弹出网盘地址，VIP 跳过广告直接获取 |
| 🔍 搜索 | 搜索历史、热门搜索、按标题 / 正文 / 标签 / 作者匹配结果（瀑布流展示） |
| ➕ 发布笔记 | 选图（最多 9 张）、标题 / 正文、分类(指标/视频/金手指)，可切换普通/收费笔记(收费需填资料地址)；存草稿后进入「我-草稿箱」继续编辑 |
| 👤 我的笔记 | 「我-笔记」展示草稿箱入口；编辑/删除自己的笔记在「笔记详情页」内操作(二次确认)；卡片展示分类标签 |
| 💬 消息 | 赞和收藏 / 评论和@ / 新增关注通知，私信会话列表与一对一聊天（含自动回复演示），tabBar 未读数字角标 |
| 👤 个人中心 | 个人资料、点关注/粉丝进入关系列表页、点获赞与收藏弹出数据统计、笔记 / 收藏 / 赞过三个 Tab |
| 🔐 登录 | 微信授权登录(getUserProfile) / 演示账号一键登录(VIP)，登录态持久化 |
| 🙋 他人主页 | 查看作者资料与其全部笔记、关注按钮 |
| 🤖 AI 助手 | 仿 DeepSeek 的聊天界面，规则式本地回复，仅文字、不支持图片上传 |

底部为**自定义 tabBar**：**首页 · AI助手 · ＋(发布) · 消息 · 我**，中间「＋」为居中的发布按钮，「消息」带未读角标。

所有点赞、收藏、关注、登录态、已发布笔记均通过 `Storage` 持久化，重启小程序后保留。

## 🚀 运行方式

1. 用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   打开本项目根目录（包含 `project.config.json`）。
2. AppID 可使用「测试号」。
3. **重要**：Mock 数据使用了在线占位图（`picsum.photos` / `pravatar.cc`），
   请在开发者工具中开启
   **「详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**，
   否则图片无法加载。正式上线时需替换为已备案并加入白名单的图片域名。

```
    │   ├── detail/             # 笔记详情

    │   ├── publish/            # 发布笔记（tabBar，中间 ＋ 按钮）
    │   ├── message/            # 消息中心（tabBar）：通知入口 + 私信列表
    │   ├── notify/             # 通知列表（赞和收藏/评论和@/新增关注）
    │   ├── chat/               # 私信一对一聊天
    │   ├── relations/          # 关注 / 粉丝列表
    │   ├── profile/            # 个人中心（tabBar）
    │   ├── user/               # 他人主页
    │   └── login/              # 登录
    ├── utils/
    │   ├── api.js              # 模拟接口层（基于 mock 数据，返回 Promise）
    │   ├── store.js            # 本地状态 + 持久化（登录态 / 点赞 / 收藏 / 关注 / 我的笔记）

    └── mock/
        └── data.js            # 模拟用户、笔记、分类、热搜数据
```

## 🔌 接入真实后端

当前数据来自 `utils/api.js` + `mock/data.js`。要接入真实后端，
只需保持 `api.js` 中各方法的函数签名与返回结构不变，将内部实现替换为
`wx.request` 调用即可，页面层无需改动。
